data- This folder will contain all the  datasets used for training, testing, or evaluation example Raw CTI data (reports, logs),Cleaned datasets,Training / testing files
Docs- This folder will contain all the related documents of current research work including Project_Report.pdf
,SRS (Software Requirement Specification), Design_Document, Literature review notes,Research papers (PDFs),Problem statement Methodology description, Experiment design,System architecture diagrams,Flowcharts,Data flow diagrams (DFD),UML diagrams
refrences- This folder contain address of all the research sources i have used including Research papers (PDFs),Citation files (BibTeX, RIS),Notes from papers,Links or summaries.
src- This folder Contains actual implementation code of  project.
results- This Folder contain actual output of experiments for example metrics.txt,evaluation.xlsx,graphs/,predictions.json,confusion_matrix.png
